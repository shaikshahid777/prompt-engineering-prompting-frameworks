# Introduction to Prompting Frameworks

## Course
Prompt Engineering

## Submitted By
**Shaik Mohammad Shaheed**

## Overview

This repository contains my assessment submission for the lesson **Introduction to Prompting Frameworks**.

## Frameworks Covered

- RTICFA
- ERA
- APEX
- TASK
- CARE
- RISE
- CASE
- ACRE

## Assessment Highlights

- Blog content creation using RTICFA
- Professional follow-up emails using ERA
- Social media marketing prompts using APEX
- Customer support prompts using TASK
- HR policy explanation using CARE
- Technical concept explanation using RISE
- Interview question generation using CASE
- Internal company announcements using ACRE

## Files

- Introduction_to_Prompting_Frameworks_Assessment.pdf

## Learning Outcomes

This assessment demonstrates how prompting frameworks provide a structured approach to designing AI prompts. By clearly defining roles, context, actions, audiences, and expected outcomes, these frameworks help generate accurate, consistent, and practical responses for real-world business and communication scenarios.
